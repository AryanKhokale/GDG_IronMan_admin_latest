# Admin Management Panel

A centralized admin dashboard designed to manage, review, and evaluate submissions across multiple competition rounds efficiently.

---

## 📌 Admin Responsibilities

The admin panel allows organizers and evaluators to:

- Review participant submissions
- Approve or reject entries
- Assign marks based on evaluation criteria
- Update submission status
- Monitor participant progress across all rounds

---

## 🧠 Round 2 — Frontend Development Review

Admins can:

- Review uploaded frontend screenshots/images
- Analyze submitted source code
- Verify functionality and implementation quality
- Set submission status (Approved / Rejected / Pending)
- Assign marks based on UI, responsiveness, creativity, and code quality

---

## 🎨 Round 3 — Poster Contest Review

Admins can:

- Review submitted poster images
- Evaluate creativity, design quality, and theme relevance
- Set submission status
- Assign marks accordingly

---

## ❓ Round 4 — Situational Riddles Review

Admins can:

- Review participant answers
- Evaluate logical reasoning and accuracy
- Set submission status
- Assign marks based on answer quality and problem-solving approach

---

## 📊 Round 5 — PPT Submission & Presentation Review

Admins can:

- Review uploaded PPT presentations
- Evaluate participant presentation performance
- Assess clarity, innovation, communication, and technical understanding
- Set submission status
- Assign final marks accordingly

---


## 🛠️ Tech Stack

- Backend: FastAPI, Python, SQLAlchemy, Asyncpg
- Database: NeonDB (PostgreSQL), Cloudinary (Cloud Storage for ppt and images)
- Admin Dashboard: Custom centralized panel

---

## 🎯 Purpose

The admin management system was developed to simplify the evaluation and judging process for multi-round competitions by providing a centralized and efficient reviewing workflow for organizers and evaluators.
